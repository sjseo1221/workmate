## 2. 각 조건의 근거

### 2.1 W9-E3 — 육안 검수가 완료 선언의 조건

W6은 자동 승인 대상이 아니었다. UI 육안 검수는 사용자 판정이 필요하다
([30-6-9](30-6-9-exit-criteria.md) §3.1).

**W9는 전환 완료를 선언하는 단계이므로, 사람이 확인해야 하는 항목이 전부 확인된 상태여야 한다.**

| 항목 | 확인 주체 |
| --- | --- |
| 자동 검증 | 명령 |
| **UI 육안 검수** | **사용자** |
| **문서 개정** | **사용자 승인** |
| **Merge·Push** | **사용자 승인** |

### 2.2 W9-E2 — 완료 기준 1~7

[계획서 §9](30-langgraph-migration-plan.md)의 9개 중 1~7은 W0~W8에서 달성됐어야 한다. 8·9는 W9가
달성한다.

| # | 기준 | 달성 단계 | W9에서 |
| --- | --- | --- | --- |
| 1 | `app/workflows/`·`WorkflowRegistry` 부재 | W7 | 확인 |
| 2 | Skill 11개 Graph 경로, Mock 없음 | W3·W5 | 확인 |
| 3 | 전체 테스트 PASS, 범위 밖 45개 무수정 | 유지 | 확인 |
| 4 | interrupt·resume·취소 | W6 | 확인 |
| 5 | `a2a_checkpoints` DROP, Checkpointer 실증 | W7 | 확인 |
| 6 | 재시도 정책 보존 | W8 | 확인 |
| 7 | 스냅샷 차이 없음 | 유지 | **diff 분류로 판정** |
| 8 | 문서 갱신 | — | **W9가 수행** |
| 9 | 증빙 기록 | — | **W9가 수행** |

**W9-T0에서 1~7을 재검증한다.** 단계별로 PASS였어도 지금 다시 확인한다 — 이후 단계가 깨뜨렸을 수
있다.

diff 분류의 입력이다. 단계마다 흩어져 있으므로 W9에서 모은다.

| 단계 | 의도적 변경 | 스냅샷 검출 |

| W4 | 멱등성 실제 구현(W4-D1) | ✗ |
| W4 | `runtime_bootstrap` 미등록 처리(W4-D3) | ✗ |
| W4 | 진행 중 중복 정책 정의(W4-D5) | ✗ |
| W5 | 멱등성이 외부에 노출 | ✗ |

## 3. 착수 전 확인 명령

```bash
cd workmate-agent

# W9-E2 — 완료 기준 1, 5
grep -rn "WorkflowRegistry" app/              # 출력 없음
ls app/workflows/                             # 존재하지 않음
grep -rn "a2a_checkpoints" app/               # 출력 없음(Migration 파일 제외)

# 완료 기준 3
WORKMATE_TEST_DATABASE_URL="..." uv run python -m unittest discover -s tests -v
git diff --stat main -- tests/                # 범위 밖 45개 파일 무변경 확인

# 완료 기준 7
uv run python -m unittest tests.contracts.test_contract_snapshots -v

# W9-E4
ls ../docs/evidence/langgraph/                # W0~W8
```

## 4. 미충족 시 처리

| 조건 | 미충족 상황 | 처리 |
| --- | --- | --- |
| W9-E1 | 단계 미완료 | 해당 단계로 복귀 |
| W9-E2 | 완료 기준 미충족 | **해당 단계로 복귀.** W9에서 고치지 않는다 |
| W9-E3 | 육안 검수 미수행 | 사용자에게 요청 |
| W9-E4 | 증빙 누락 | 해당 단계 증빙 작성 |
| W9-E5, E6 | 목록 불완전 | 각 단계 증빙에서 수집 |

### 4.1 "W9에서 고치지 않는다"

W9는 판정 단계다. 구현 문제를 발견하면 **해당 단계로 돌아간다.**

| 발견 | 처리 |
| --- | --- |
| 완료 기준 6(재시도) 미충족 | W8로 복귀 |
| 스냅샷 차이 | 원인 단계로 복귀 |
| 문서와 구현 불일치 | **문서를 고친다**(§1.1) — 단 96번 §11 불변식은 예외 |

## 5. 선행 조건의 특수성

W9는 **선행 조건에 사람의 판정이 둘 들어간다.**

| 조건 | 주체 |
| --- | --- |
| W9-E1, E2, E4, E5, E6 | 기계적 확인 |
| **W9-E3** | **사용자 판정**(UI 육안 검수) |

W6과 같은 성격이다. 전환의 시작(W0)과 끝(W9)이 모두 사람의 확인을 요구한다.
