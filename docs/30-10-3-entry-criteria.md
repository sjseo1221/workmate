## 2. W10-E4가 가장 중요하다

[05번 문서 §1](05-ai-security-operations.md)의 표가 LLM의 역할을 **텍스트 생성으로 한정**하고 있다.

| LLM | 코드 |
| --- | --- |
| 요약과 자연어 표현 | 날짜 범위 계산 |
| 회의 분석 Text와 Action Item 후보 추출 | 인증과 접근권한 |
| 보고서 문장 작성 | 중복 제거와 상태 전이 |
| 검색 문맥 기반 답변 | 우선순위 점수와 출력 검증 |

**"도구를 고르고 실행 순서를 정한다"가 LLM 칸에 없다.**

### 2.1 이건 누락이 아니라 설계였다

`assistant_router`가 2026-08-17에 도입될 때도 LLM은 **분류기**로 규정됐다
([18번 설계 결정 2](18-workmate-assistant-implementation-plan.md)). "어떤 Skill인가"를 고르는 것까지는
텍스트 이해의 연장으로 봤고, **실행 순서와 다단계 계획은 애초에 LLM에 주지 않았다.**

| 구분 | 현재 |
| --- | --- |
| Skill 하나 고르기 | LLM (분류) |
| 인자 뽑기 | LLM (구조화 추출) |
| 실행 순서 정하기 | **없음** — 항상 1개 |
| 결과 보고 재계획 | **없음** |

ReAct는 아래 두 줄을 LLM 칸에 추가하는 일이다. **문서를 먼저 고쳐야 하는 이유다.**

### 2.2 개정은 "넓히기"가 아니라 "경계 다시 그리기"다

무제한으로 넓히면 `AGENTS.md`("우선순위 점수는 결정적으로 계산한다", "LLM이 Task 순위와 근거 ID를
생성하거나 변경하지 않도록 한다")와 충돌한다.

**개정안은 넓히는 범위를 정확히 한정한다.**

```
[추가]  LLM: 도구 선택과 호출 순서 (assistant_ask 한정)

[유지·명시]  코드: 점수·순위·근거 ID·날짜 경계·권한·중복 제거·상태 전이
             → 도구가 반환한 값을 Agent가 바꾸지 않는다
```

개정안 전문과 승인 절차는 [30-10-10](30-10-10-approval.md) §3에 있다.

## 3. W10-E5 — 규칙 목록화가 왜 선행 조건인가

`_SKILL_CATALOG` 134줄에는 실사용으로 다듬어진 규칙이 촘촘히 들어 있다. **이 목록 없이 구현을 시작하면
무엇이 빠졌는지 알 수 없다.**

```
규칙표 없이 구현
  → ReAct가 대부분 잘 동작함
  → "지난주 보고서" 요청에서 날짜가 7일 더 빠짐
  → 원인: 카탈로그 3행의 "7일을 두 번 빼지 마라"가 어디에도 안 옮겨짐
  → 발견 시점: 사용자 신고
```

규칙표는 **회귀 테스트의 목록이기도 하다.** 각 행이 테스트 케이스 하나에 대응한다
([30-10-8](30-10-8-traceability.md) §2).

### 3.1 목록화의 완료 조건

| 조건 | 판정 |
| --- | --- |
| 134줄의 모든 규칙성 문장이 표에 있다 | 줄 단위 대조 |
| 각 규칙에 이전처가 지정됐다 | 도구 description / Schema / 코드 / 시스템 프롬프트 |
| 각 규칙에 회귀 케이스가 있다 | 입력 → 기대 도구·인자 |
| 이전처가 "코드"인 규칙은 도구 기본값 설계가 있다 | W10-D1 |

**"이건 규칙이 아니라 설명"으로 분류한 줄도 기록한다.** 판단을 남겨야 나중에 검증할 수 있다.

## 4. 선행 조건이 아닌 것

| 항목 | 왜 선행 조건이 아닌가 |
| --- | --- |
| W9-B7 스트리밍 | 있으면 좋지만 없어도 ReAct는 동작한다 |
| W9-B8 트레이싱 | 동상. API Key 승인이 별건 |
| 도구 집합 재설계(D7-3의 B안) | Skill 10개 그대로 시작한다 |
| 비용 예산 승인 | W10-T10에서 측정한 뒤 판단 |

## 5. 착수 판정 체크리스트

```
[ ] W9 증빙에 latest_approved_run_id가 있다          (W10-E1)
[ ] W6-V7 육안 검수가 PASS로 기록됐다                (W10-E2)
[ ] D7-1 ~ D7-7이 승인 기록에 확정값으로 남았다       (W10-E3)
[ ] 05번 문서 §1이 개정되고 승인 기록이 있다          (W10-E4)
[ ] 카탈로그 규칙표가 §3.1의 네 조건을 만족한다       (W10-E5)
[ ] 루프 예산 수치가 확정됐다                        (W10-E6)
```

**하나라도 비면 W10을 시작하지 않는다.** `HANDOFF.md`에 미충족 항목과 대기 사유를 기록한다.
