## 4. 판정 규칙

- **W9-V2에서 설명 불가 차이가 1건이라도 있으면 완료 판정 중단.** 원인 단계로 복귀
- **W9-V5 FAIL은 범위 이탈이다.** 범위 밖 테스트를 왜 고쳤는지 설명이 필요하다
- W9-V3에서 96번 §11 불변식과 구현이 다르면 **구현을 고친다**(문서가 아니라)
- W9-V6 FAIL은 Push 금지

## 5. 검증과 승인의 관계

| 검증 | 자동 판정 | 사용자 판정 |
| --- | --- | --- |
| W9-V1~V2, V4~V8 | ✓ | |
| W9-V3(문서 정합) | 작성은 자동 | **반영은 승인 후** |
| (W6-V7 육안 검수) | | **사용자**(선행 조건) |
| Merge·Push | | **사용자** |

**W9는 자동 검증이 전부 PASS여도 사용자 승인 없이 완료되지 않는다.**
