## 2. 작업 상세

### W7-T1 — 잔여 참조 전수 조사

**내용**

```bash
# 운영 코드 — 여기가 비어야 한다
grep -rn "from app.workflows\|import app.workflows" app/
grep -rn "workflow_registry\|WorkflowRegistry\|WorkflowRequest\|WorkflowResult" app/
grep -rn "save_checkpoint" app/

# 테스트 — 갱신 대상 목록
grep -rln "app.workflows" tests/
grep -rln "external_sync\|weekly_classification" tests/

# 문서 — 링크 정정 대상
grep -rn "app/workflows" ../docs/ | grep -v "docs/30-"
```

**산출** 참조 목록 3종(운영·테스트·문서).

**주의** `app/`에서 출력이 나오면 **W5가 덜 끝난 것**이다. W7을 진행하지 말고 해당 호출을 Graph로
교체한다.

**난이도** 낮음 / **비중** 10%

**내용** `app/workflows/weekly_classification.py` → `app/domain/weekly_classification.py`

**주의**
- **내용 무수정**(W7-R9). `git mv`를 써서 이동으로 인식되게 한다
- 호출자(`app/graph/skills/weekly_report.py`)의 import 갱신
- 기존 [app/domain/weekly.py](../workmate-agent/app/domain/weekly.py)와 합칠지 별도로 둘지 판단 —
  **별도 파일 권장**(이동을 명확히 하고 내용 수정을 피한다)

**난이도** 낮음

### W7-T4 — 테스트 import 갱신

**내용** W7-T1에서 파악한 테스트의 import 경로를 새 위치로 바꾼다.

**대상 예상**

| 테스트 | 참조 |
| --- | --- |
| [test_google_adapters.py](../workmate-agent/tests/test_google_adapters.py) | `external_sync` |
| [test_proposals.py](../workmate-agent/tests/test_proposals.py) | `external_sync` |
| [test_weekly_source_link.py](../workmate-agent/tests/test_weekly_source_link.py) | `weekly_classification` |
| [test_m2_1_integration.py](../workmate-agent/tests/test_m2_1_integration.py) | 동상 |

**W3에서 이미 재작성된 테스트는 새 경로를 쓰고 있을 수 있다.** W7-T1의 조사 결과로 확정한다.

**왜 삭제보다 먼저인가** 테스트가 `app.workflows`를 import한 채 패키지를 지우면 **수집 단계에서 전부
실패**한다. 어떤 테스트가 왜 실패했는지 구분할 수 없다.

**난이도** 낮음

### W7-T8 — DROP Migration 작성

**내용**

```sql
-- migrations/007_drop_a2a_checkpoints.sql
-- W7(D6=B): LangGraph Checkpointer가 대체했으므로 자체 Checkpoint 테이블을 폐기한다.
-- 001에서 생성했고 {task_id}:submitted 마커만 기록했으며 읽는 코드가 없었다(W0 조사).
DROP TABLE IF EXISTS a2a_checkpoints;
```

**주의** `IF EXISTS`가 멱등성을 준다(W7-V6).

**난이도** 낮음

### W7-T9 — Migration 계약 테스트

**내용**

1. `001` 검증에 주석 추가 — "007에서 DROP됨"
2. `007` DROP 검증 추가

```python
def test_drop_migration_removes_checkpoint_table(self) -> None:
    migration = Path(__file__).parents[1] / "migrations" / "007_drop_a2a_checkpoints.sql"
    sql = migration.read_text(encoding="utf-8")
    self.assertIn("DROP TABLE IF EXISTS a2a_checkpoints", sql)
```

**주의** `001`의 기존 검증은 **유지**한다(W7-D4). Migration 이력의 사실이다.

**난이도** 낮음
