## 공통 재검수 규칙

1. 이전 실행은 보존하고 새 `runs/{run_id}/result.md`를 만든다.
2. 검증 명령·완료 기준·미실행 여부를 결과에 명시한다.
3. `PASS_WITH_CAVEAT`, `FAIL`, `보류`, `경고`, 미실행이 하나라도 남으면 통합 검수를 다시 중단한다.
4. 세 항목의 새 결과가 모두 정확히 `PASS`인 경우에만 M0.2 통합 결과를 자동 승인한다.
5. 실제 회의 음성 평가와 운영 검색 답변 가능성은 각각 M3.3·M4.4에서 별도 검증하며, 해당 범위를 M0.2 결과에 다시 섞지 않는다.

## 순서

```text
M0.2-02 범위·결과 재정리
→ M0.2-03 범위·결과 재정리
→ M0.2-04 사용자 로컬 Gmail 결과 전용 증빙

```
