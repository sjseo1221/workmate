# W9-9 — 완료 정의

> [30-9-w9-docs-evidence.md](30-9-w9-docs-evidence.md) §9의 상세 문서.

## 1. 완료 조건 (Exit criteria)

| # | 조건 | 판정 근거 |
| --- | --- | --- |
| E-1 | W9-V1~V8 전부 PASS | 각 검증 |
| E-2 | 계획서 §9 완료 기준 9개 전항 충족 | W9-V1 |
| E-3 | **스냅샷 diff에서 설명 불가 차이가 0** | W9-V2 |
| E-4 | 문서 개정이 **사용자 승인 후** 반영됨 | 승인 기록 |
| E-5 | `latest_approved_run_id` 확정 후 **Merge·Push 승인** | 동상 |

### 1.1 E-3이 전환의 최종 판정이다

```
27건
├ 동일           25건  ← 전환이 동작을 바꾸지 않았다
├ 의도적 변경     2건  ← 계획대로 바꿨다
├ 미검증        (목록) ← 애초에 검증 대상이 아니었다
└ 설명 불가       0건  ← **이것이 0이어야 전환이 성공한 것이다**
```

1건이라도 있으면 "왜 바뀌었는지 모르는 변경"이 있다는 뜻이고, 전환을 신뢰할 수 없다.

### 1.2 E-4·E-5가 사용자 승인을 요구한다

W9는 **자동 승인만으로 완료되지 않는다.**

| 항목 | 자동 | 사용자 |
| --- | --- | --- |
| 검증 실행 | ✓ | |
| 증빙 작성 | ✓ | |
| diff 분류 | ✓ | |
| **문서 개정 반영** | | **✓** |
| **Merge** | | **✓** |
| **원격 Push** | | **✓** |

## 4. 승인 절차

### 4.1 W9는 자동 승인 대상이 아니다

| 조건 | W9 해당 여부 |
| --- | --- |
| 외부 OAuth·실제 Provider 호출 | 없음 |
| 공개 Schema 변경 | W6에서 이미 |
| UI 육안 검수 | 선행 조건(W6-V7) |
| 모델 평가 | 없음 |
| **문서 개정** | **있음** |
| **원격 Push** | **있음** |

→ **두 항목이 사용자 승인을 요구한다.**

### 4.2 승인이 두 번 필요하다

| 시점 | 승인 대상 |
| --- | --- |
| **W9-T6** | 문서 개정안(97·96·07번) + `AGENTS.md` 제안 |
| **W9-T10** | Merge·Push |

**Push 승인 질문은 실제 Push 조건에 도달했을 때 한 번만 한다**(`AGENTS.md`).

### 4.3 완료 시 기록

```
latest_run_id:          {run_id}
latest_run_status:      PASS
latest_approved_run_id: {run_id}
approved_at:            (사용자 승인 시각)
reviewer:               사용자 확인
자동 진행 판정:          해당 없음 — 전환 종료
전환 완료:              예
기준 Commit:            workmate-agent@8043c1e (W0)
최종 Commit:            {SHA}
스냅샷 diff:            동일 25 / 의도적 변경 2 / 설명 불가 0
의도적 변경:            5건
알려진 한계:            9건
후속 백로그:            10건
```

### 4.4 승인이 불가한 경우

| 상황 | 처리 |
| --- | --- |
| **설명 불가 차이 ≥ 1** | **완료 판정 중단.** 원인 단계로 복귀 |
| 완료 기준 미충족 | 동상 |
| 문서 개정안 반려 | 수정 후 재제출 |
| W6-V7 육안 검수 미수행 | 사용자에게 요청 |
| Push 전 체크리스트 미완료 | 보완 |

후행 단계가 없다. 남는 것은 [30-9-12](30-9-12-backlog.md)의 후속 백로그 10건이다.

| 우선순위 | 항목 |
| --- | --- |
| 중간 | HTTP 429 재시도, `AUTH_REQUIRED` 상태, 오케스트레이터 대응 |

**별도 계획으로 다룬다.** W9에서 착수하지 않는다.
